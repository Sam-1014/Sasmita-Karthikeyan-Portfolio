## 🚀 Selected Projects

### 🌊 FloatMind

An intelligent ocean-data platform designed to explore, analyze, visualize, and interpret subsurface ocean information using sources such as **Argo profiles and satellite observations**.

The project focuses on bringing together **ocean data, machine learning, visualization, APIs, and intelligent analysis** into a unified platform.

**Focus:** AI • Data Science • Ocean Intelligence • APIs • Visualization

---

### 💬 FloatChat

An intelligent interface for interacting with ocean and environmental datasets through **natural-language queries, data exploration, and visualization**.

The goal is to make complex scientific datasets more accessible by allowing users to interact with data in a more intuitive way.

**Focus:** AI • Natural Language Interaction • Data Science • Visualization

---

### 🔋 EV Battery Health & Thermal Runaway Prediction

A research-oriented system combining **deep learning, machine learning, embedded sensing, and real-time inference** for EV battery monitoring.

The system explores battery **State of Health (SOH), Remaining Useful Life (RUL), and thermal-risk prediction**, with a focus on practical deployment through embedded hardware.

**Focus:** Machine Learning • Deep Learning • Embedded AI • EV Systems • Research

---

### 🤖 RoboMarine

An object-oriented autonomous underwater robot management and mission-control system developed using **Java**.

The project models underwater robotic missions, robot management, mission planning, and system-level interactions using object-oriented design principles.

**Focus:** Java • OOP • Autonomous Systems • Robotics • Ocean Technology

---

### 🔬 Qubit View

An interactive 3D visualization concept exploring the representation of quantum-inspired computational and research processes through an engaging web interface.

**Focus:** 3D Visualization • Web Development • Interactive Design

## ⚙️ Run Locally

### 1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

### 2. Navigate to the project

cd YOUR_PROJECT_FOLDER

### 3. Create a virtual environment

python -m venv venv

### 4. Activate the environment on Windows

venv\Scripts\activate

### 5. Install dependencies

pip install -r requirements.txt

### 6. Start the Django development server

python manage.py runserver

### 7. Open the portfolio

http://127.0.0.1:8000/
